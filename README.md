# Frontier DataOps Studio

An open-source AI DataOps platform for managing datasets, reviewing annotations, validating dataset quality, and analyzing annotation workflows.

## Project Structure

```
frontier-dataops-studio/
├── frontend/          # React + TypeScript + Tailwind CSS
├── backend/           # FastAPI Python backend (coming soon)
└── docs/              # Project documentation
```

## Quick Start

```bash
cd frontend
npm install
npm run dev
```
