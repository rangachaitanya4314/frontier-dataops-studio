# Roadmap

## v0.1 — Frontend Foundation ✅ (Current)

- [x] Project scaffolding (Vite + React + TypeScript)
- [x] Design system with dark/light theme
- [x] Responsive layout shell (sidebar, topbar)
- [x] Dashboard with stats and recent activity
- [x] Projects listing with grid/list view
- [x] Create project wizard (multi-step form)
- [x] Project detail page with tabs
- [x] Dataset upload interface (UI only)
- [x] Mock data layer with typed API stubs

## v0.2 — Backend Foundation

- [ ] FastAPI project setup
- [ ] PostgreSQL database with SQLAlchemy models
- [ ] REST API for projects CRUD
- [ ] REST API for datasets CRUD
- [ ] Connect frontend API stubs to real endpoints
- [ ] File upload endpoint for datasets

## v0.3 — Dataset Management

- [ ] Real file upload with progress tracking
- [ ] Dataset versioning
- [ ] Image/CSV/JSON preview
- [ ] Dataset statistics computation
- [ ] Data validation rules engine

## v0.4 — Annotation

- [ ] Annotation canvas (bounding box)
- [ ] Classification annotation mode
- [ ] Annotation assignment and tracking
- [ ] Keyboard shortcuts for annotation

## v0.5 — Quality & Review

- [ ] Review workflow (approve/reject/flag)
- [ ] Inter-annotator agreement metrics
- [ ] Quality score dashboards
- [ ] Annotation guidelines editor

## v0.6 — Authentication & Teams

- [ ] User authentication (OAuth / email)
- [ ] Team management
- [ ] Role-based access control
- [ ] Audit logging

## Future

- AI-assisted annotation (auto-labeling, suggestions)
- Dataset export in COCO, Pascal VOC, YOLO formats
- Webhook integrations
- Plugin system for custom annotation types
